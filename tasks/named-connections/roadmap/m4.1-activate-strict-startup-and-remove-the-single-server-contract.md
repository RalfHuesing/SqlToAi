# M4.1 — Activate strict startup and remove the single-server contract

> **Status:** [x] Closed
> **Milestone:** [M4 — Hard cut, operating documentation and final evidence](../roadmap.md#m4--hard-cut-operating-documentation-and-final-evidence)
> **Index:** [Roadmap Index](../roadmap.md)

---

## Depends on
M3 ([M3.1](m3.1-route-schema-inspection-and-existing-schema-exports.md)–[M3.4](m3.4-audit-service-and-transport-coverage.md)).

## Intention
make every shipped entry point accept only the approved contract.

## Scope
[UserConfiguration](../../../src/SqlToAi/Configuration/UserConfiguration.cs),
ConfigurationResolver, options validation, Program/DI, StartupHarness, main/demo
JSON, integration/test-only TLS overlays, package-smoke configuration inputs,
remaining fixtures and environment examples. Remove obsolete top-level options,
old overloads and unused preparation scaffolding. Update [configuration](../../../docs/configuration.md),
[security](../../../docs/security.md), [architecture](../../../docs/architecture.md),
[tools](../../../docs/tools.md), [development](../../../docs/development.md),
[exploration](../../../docs/exploration.md), [SETUP](../../../SETUP.md) and affected
public [README](../../../README.md) setup examples in this cutover slice.

## Exclusions
importing/rewriting/backing up user settings, migration commands,
release/version/publishing changes and weakening test or application TLS defaults.

## Acceptance
require at least one valid server; validate grants after binding
and supported expansion. Reject exact/case-only aliases inside each JSON Servers
object before lossy merge, but allow normal cross-source overrides. Inspect the
required base file, active environment file and process keys for obsolete
sections/prefixes even when overridden. Missing base settings still fail;
invalid configuration exits 1 before SQL/MCP with safe actionable stderr and no
diagnostic stdout or settings writes. Direct options/DI use equivalent effective
validation; source checks stay at the loading boundary. Provider SQL paths and
other surviving expansion/path rules remain intact. Main grants stay empty;
demo grants are qualified and examples use environment-based SQL credentials.
Public setup/update guidance includes a complete new example and manual hard-cut
instructions. No runtime consumer can still bind or infer the old contract.

## Evidence
- Obsolete root sections (`SqlServer`, `MetadataProvider`, `AnonymizationRules`) and `SqlServerOptions` class removed from `SqlToAiOptions`.
- `ConfigurationResolver` validates presence of >= 1 server, alias pattern (`^[A-Za-z][A-Za-z0-9_-]*$`), non-empty server address, and that database grants reference configured servers.
- `UserConfiguration.LoadOrReport` inspects every effective JSON path in base and active environment sources before merge. Environment paths normalize `__` to `:`; exact obsolete product sections and descendants fail with safe known-prefix diagnostics, while unrelated lookalikes remain valid. Corrections `7f88de2` and `00f5b58` include isolated child-process and effective DI-options evidence in the [deep audit](../audit.md#r2a--provider-equivalent-environment-path-rejection).
- Obsolete single-server methods removed from `IDatabaseConnectionFactory`, `ISecurityGuard`, `IAccessLevelProvider`, `IAnonymizationRuleProvider`, `IAnonymizationPolicyResolver`, `IMetadataProvider`, `SecondaryConnectionBuilder`, `TableSchemaRenderer`, and `QuerySafetyValidator`.
- `appsettings.json`, `demo-profile.json`, integration overlays, and test harness updated to the qualified `Servers.<alias>` schema.
- Documentation updated across `docs/configuration.md`, `docs/security.md`, `docs/architecture.md`, `docs/tools.md`, `docs/development.md`, `docs/exploration.md`, `SETUP.md`, and `README.md`.
- Test suite: 1474 tests passed, 0 failed, 19 skipped (TlsConnectionIntegrationTests without explicit profile). All projects compile cleanly with zero warnings (`-warnaserror`).
