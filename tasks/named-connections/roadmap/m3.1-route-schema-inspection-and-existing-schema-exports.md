# M3.1 — Route schema inspection and existing schema exports

> **Status:** [x] Closed
> **Milestone:** [M3 — Remaining services and public argument surfaces](../roadmap.md#m3--remaining-services-and-public-argument-surfaces)
> **Index:** [Roadmap Index](../roadmap.md)

## Depends on
M2 ([M2.1](m2.1-scope-metadata-central-rules-and-rule-caches.md)–[M2.5](m2.5-audit-provider-token-and-execution-isolation.md)).

## Intention
preserve database identity through metadata and export composition.

## Scope
[SchemaService](../../../src/SqlToAi/Database/SchemaService.cs), scalar/batch
schema, object search and all separate detail/definition operations; export
discovery, [SchemaExportService](../../../src/SqlToAi/Cli/SchemaExportService.cs) and
its typed identities/rendering contexts. Pass one resolved target through helpers.

## Exclusions
database list/search ([M3.3](m3.3-expose-server-discovery-and-qualified-mcp-cli-arguments.md)), data/CSV export, changes to selection,
batch budgets, dump layout, file safety or offline provider exclusions.

## Acceptance
same-name targets route correctly for scalar/batch schema, every
detail tool, selected/all MCP export and legacy full CLI export. SchemaOnly and
pre-SQL access checks remain effective. Existing database headings use canonical
targets, but SQL/DDL/object identifiers stay raw. Batch envelopes/limits, offline
rendering without provider calls, partial-output and cancellation behavior hold.

## Evidence
- `SchemaService.cs` routes all schema methods (`GetSchemaAsync`, `GetSchemaBatchAsync`, `SearchObjectsAsync`, `GetSchemaForeignKeysAsync`, `GetSchemaIndexesAsync`, `GetSchemaConstraintsAsync`, `GetTriggerDefinitionAsync`, `ResolveObjectsAsync`, `GetSelectedExportObjectsAsync`, `GetExportTriggerDefinitionAsync`) through `ResolveAndVerifyTargetAsync(databaseName)`.
- Unqualified targets are rejected with `SQL-AI-0001` before any connection or catalog interaction.
- Targets blocked by security policy/whitelist are rejected with `SQL-AI-0104` before any SQL execution.
- Canonical target headings formatted via `target.QualifiedName`, while SQL, DDL, and database object identifiers remain raw.
- `IMetadataProvider` and `MetadataProvider` support `DatabaseTargetContext` overloads and resolve provider sources per server owner.
- `SchemaExportService.cs` exports schema overviews with canonical `$"{serverAlias}/{databaseName}"` targets.
- Dedicated acceptance tests in `SchemaServiceTargetIsolationTests.cs` verify unqualified rejection, whitelist enforcement, same-database multi-server isolation, and raw DDL/SQL queries.
- Build: `dotnet build SqlToAi.slnx` completed with 0 warnings, 0 errors under `-warnaserror`.
- Test: `dotnet test SqlToAi.slnx` completed with 1,433 passed, 19 skipped, 0 failed.
