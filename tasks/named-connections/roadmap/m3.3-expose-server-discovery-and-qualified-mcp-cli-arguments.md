# M3.3 — Expose server discovery and qualified MCP/CLI arguments

> **Status:** [x] Closed
> **Milestone:** [M3 — Remaining services and public argument surfaces](../roadmap.md#m3--remaining-services-and-public-argument-surfaces)
> **Index:** [Roadmap Index](../roadmap.md)

---

## Depends on
[M3.1](m3.1-route-schema-inspection-and-existing-schema-exports.md)–[M3.2](m3.2-route-comparison-measurements-benchmarks-and-indexes.md).

## Intention
let callers discover aliases and address only explicit targets.

## Scope
database discovery services; [ToolRegistry](../../../src/SqlToAi/Mcp/ToolRegistry.cs),
dispatcher, SDK registrations, source-generated JSON metadata, registry-generated
CLI and `export-schema` binding; update exploration scenarios, owning fixtures
and the expected tool inventory in [package smoke checks](../../../scripts/smoke-package.ps1).

## Exclusions
host configuration activation, credential/hostname discovery,
connection probes for listing aliases and implicit server selection.

## Acceptance
`sql_list_servers` has no arguments and returns canonical aliases
as one JSON array in text content without SQL calls. List/search require `server`;
search additionally requires unchanged `search_term` and matches only raw names
with `OrdinalIgnoreCase` substring semantics. Catalog work contacts one selected
server. Existing static fallback deduplicates only that owner's grants, applies
exclusions/policy and claims no existence guarantee; TLS/timeouts return their
errors and cancellation propagates. Registered SDK invocation, dispatcher and
generated CLI tests verify argument failures, qualified targets, result shapes
and MCP `isError`/CLI failure behavior; update the SQL tool count to 19.

## Evidence
- `ISchemaService.ListServers()`, `ListDatabasesAsync(server, ...)` und `SearchDatabasesAsync(server, searchTerm, ...)` eingeführt.
- `DatabaseTargetResolver.ConfiguredServerAliases` liefert kanonische konfigurierte Server-Aliase.
- `SchemaService.ListServers()` liefert kanonische Aliase ohne SQL-Verbindungsaufbau (0 Connections).
- `SchemaService.ListDatabasesAsync` nutzt `PrimaryConnection.OpenCatalogAsync` für den gewählten Server, fragt `sys.databases` ab, filtert mit `_securityGuard.IsTargetAllowed` und beschränkt den statischen Fallback strikt auf Grants des Ziel-Servers.
- `SchemaService.SearchDatabasesAsync` validiert `server` und `search_term` und führt case-insensitive Substring-Matching durch.
- `ToolRegistry`: `sql_list_servers` registriert, `sql_list_databases` und `sql_search_databases` erfordern `server`. MCP-Toolanzahl von 18 auf 19 erhöht.
- `ToolDispatcher`, `SqlMcpToolRegistrations`, `scripts/smoke-package.ps1` und `ExploreSqlTools.cs` auf 19 Tools und `server`-Parameter aktualisiert.
- Tests: `ServerDiscoveryTargetIsolationTests.cs`, `ToolCommandFactoryTests.cs`, `ToolDispatcherTests.cs`, `ToolRegistryTests.cs`, `McpModelsTests.cs`, `SchemaServiceTests.cs`, `SchemaServiceIntegrationTests.cs`, `PrimaryConnectionFailureTests.cs`. Build (0 Warnungen, 0 Fehler) und Tests (1468 bestanden).
