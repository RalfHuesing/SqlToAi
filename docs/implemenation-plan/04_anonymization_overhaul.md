# Implementation Plan: Anonymization Overhaul & New Access Level (Step 4)

This plan details the changes to update database access levels and the string anonymizer to support universal consistent-random anonymization.

## Proposed Changes

### [MODIFY] Core Domain Component

#### [MODIFY] [AccessLevel.cs](file:///c:/Daten/Entwicklung/Ralf/SqlToAi/src/SqlToAi/Domain/AccessLevel.cs)
* Introduce new level `ReadOnlyAnonymized` (integer value `2`).
* Shift clear-text `ReadOnly` / `ReadData` to integer value `3`.
* Shift `ReadWrite` to integer value `4`.
* Update descriptions and comments.

---

### [MODIFY] Security Domain Component

#### [MODIFY] [AccessLevelProvider.cs](file:///c:/Daten/Entwicklung/Ralf/SqlToAi/src/SqlToAi/Security/AccessLevelProvider.cs)
* Update `ParseAccessLevel` helper to support new string mappings (`ReadOnlyAnonymized`, `ReadDataAnonymized`, `ReadOnlyClear`) and updated integer mappings:
  - `2` -> `ReadOnlyAnonymized`
  - `3` -> `ReadOnly`
  - `4` -> `ReadWrite`
* Update default fallback when `AccessCheckSql` is empty: if `SqlDatabase.ReadOnly` is true, fall back to `AccessLevel.ReadOnlyAnonymized` (secure by default).

---

### [MODIFY] Anonymization Domain Component

#### [MODIFY] [Anonymizer.cs](file:///c:/Daten/Entwicklung/Ralf/SqlToAi/src/SqlToAi/Anonymization/Anonymizer.cs)
* Remove the `Rules` mapping logic that matches column names.
* By default, if anonymization is enabled, all columns are anonymized *unless* they match one of the glob patterns in `ExcludedColumns` (e.g. `Id`, `*Id`, `*Code`, `Status`, `State`, etc.).
* Overhaul `Scramble` algorithm to use consistent random scrambling:
  - Compute a stable 32-bit hash (FNV-1a) of the input value.
  - Seed a `Random` PRNG with this stable hash.
  - For each character, substitute it with a random uppercase letter (if uppercase), lowercase letter (if lowercase), or digit (if digit) generated by the PRNG.
  - Special characters, punctuation, and layout (like `@`, `.`, spaces) remain unchanged.
  - This ensures that identical input strings (like "Ralf") always map to the exact same random-looking scrambled string of the same length (e.g., "Kjsd").
