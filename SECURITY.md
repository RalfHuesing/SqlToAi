# Security policy

SqlToAi's GitHub private vulnerability reporting is enabled. Submit suspected
vulnerabilities through [GitHub's private report form](https://github.com/RalfHuesing/SqlToAi/security/advisories/new).
Do not put vulnerability details, exploit steps, credentials, customer data, or
affected database information in a public issue.

For non-sensitive setup questions and bugs, GitHub Issues are enabled. Follow the
[sanitized reporting guidance](docs/development.md#support-and-contributions).
